Curve+: Intelligent Color Measurement, Faster Press Profiling, and Greater Production Efficiency

AdaSphere · Press Calibration

Software In today’s highly competitive printing and packaging industry, delivering consistent color while controlling production costs is essential. Print providers are expected to achieve repeatable results, minimize waste, and improve productivity without compromising quality. Curve+ is an advanced calibration and color management solution designed to simplify press calibration, optimize profiling, and streamline measurement workflows. By combining intelligent automation with accurate measurement using the TECHKON SpectroDens, Curve+ enables printers to achieve predictable, repeatable color across every production run.

Integrated Measurement with TECHKON SpectroDens

Accurate measurement is the foundation of successful color management. Curve+ integrates powerful measurement capabilities directly into its VERIFY, CALIBRATE, and BLEND tools, allowing operators to perform every stage of the color management process within a single workflow. Working seamlessly with the TECHKON SpectroDens, Curve+ provides precise color measurements for calibration, verification, and process control. This integration eliminates unnecessary software switching, reduces operator effort, and helps maintain consistent print quality throughout production.

Smarter Measurement, Simplified Workflows

Curve+ is designed to make measurement faster, easier, and more efficient The software supports flexible target orientation, allowing measurement targets to be rotated for the most convenient scanning direction without affecting accuracy. This improves usability across a wide variety of print layouts and production environments. To further increase efficiency, Curve+ incorporates intelligent scanning technologies that reduce repetitive setup and operator intervention.

MemoryScan Technology

One of Curve+’s innovative productivity features is MemoryScan, which remembers previously measured target positions for compatible workflows. This significantly speeds up repeated measurements by allowing operators to quickly position and scan targets without reconfiguring the setup each time, reducing production time while improving consistency.

Intelligent Measurement Control

Curve+ automatically manages critical measurement parameters to ensure every reading is performed using the correct instrument configuration. By standardizing measurement conditions throughout the workflow, Curve+ minimizes operator error, improves repeatability, and ensures that production measurements remain consistent with reference data. The result is greater confidence in every calibration, verification, and profiling process.

Virtual Press Run: Eliminating an Entire Press Run

One of the most innovative features available in the Curve+ Complete License is Virtual Press Run (VPR). Traditionally, creating an ICC profile from a G7+-calibrated press requires two separate press runs. The first press run is used to determine the G7+ calibration curves. A second press run is then required to print the profiling target using those newly generated curves before an accurate press profile can be created. This traditional workflow consumes additional paper, ink, press time, labor, and production capacity. Virtual Press Run changes that completely. Instead of requiring a second physical press run, Curve+ mathematically applies the calculated G7+ calibration curves directly to the measurements collected during the first run. The software generates a virtual dataset that accurately represents the results of a second calibrated press run, eliminating the need to return the press to production. The result is faster implementation, lower operating costs, and a significantly more efficient profiling process.

Key Benefits of Virtual Press Run

Virtual Press Run delivers measurable operational and financial advantages, including:

  • Eliminates the second press run required for profiling
  • Reduces paper, ink, and material consumption
  • Minimizes press setup time
  • Lowers production and labor costs
  • Accelerates G7+ calibration and ICC profile creation
  • Increases overall production efficiency
  • Supports sustainable printing by reducing waste
  • Delivers a rapid return on investment, often within the first few production jobs

Built for Modern Print Production

Curve+ has been developed to integrate naturally into existing production environments. The software communicates with the TECHKON SpectroDens only when measurements are required, allowing operators to use the instrument across multiple applications without unnecessary interruptions. This flexible approach simplifies daily production while maximizing equipment utilization.

Transforming Color Management

By combining intelligent measurement, advanced automation, and the precision of the TECHKON SpectroDens, Curve+ provides a comprehensive solution for modern print production. Whether your objective is reducing waste, improving productivity, achieving G7+ calibration, or delivering consistent color across every print run, Curve+ simplifies the entire color management workflow. For commercial printers, packaging converters, and print professionals striving for greater efficiency and predictable color quality, Curve+ represents a smarter approach to calibration, measurement, and press profiling—helping transform color management into a faster, more accurate, and more cost-effective process.
